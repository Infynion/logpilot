A secure, high-performance logpilot and error monitor that captures exceptions, PHP errors, and API failures.

== Description ==

Logpilot - Advanced Error & Activity Monitor by Infynion replaces standard scattered logs with an organized, encrypted, and easy-to-use WordPress interface. It tracks PHP Errors, Fatal Exceptions, WP API failures, and silent AJAX failures.

### Features
* Dashboard interface for viewing logs
* Encrypted payload storage
* Grouping of identical errors by occurrences
* Automatic log trimming and cleanup
* Administrator notifications for fatal events

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/logpilot` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Configure the settings under **Tools > Logpilot**.
